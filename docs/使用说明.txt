MoeCard 1.0.0  —  数字商品自动发货商城

═══════════════════════════════════════════════════════════
 本地试用
═══════════════════════════════════════════════════════════

  双击 MoeCard.exe，然后浏览器打开：

      http://127.0.0.1:8080

  首次启动会自动跳到 /setup 创建管理员账号。
  密码要求：至少 8 位，且包含字母/数字/符号中的两类。

  程序会在同目录下自动创建：
      data\      SQLite 数据库
      storage\   上传的图片

  这两个目录就是全部数据，备份它们即可。


  想看完整的路由表（排查接口是否注册）：
      set GIN_MODE=debug && MoeCard.exe

═══════════════════════════════════════════════════════════
 改掉默认的后台入口（可选）
═══════════════════════════════════════════════════════════

  默认后台在 /admin，扫描器天天在撞这个路径。

  后台 → 商城设置 → 安全 → 入口路径，改成自己的一串（至少 8 位，
  只能用小写字母、数字、中划线、下划线）。保存后：

      旧的 /admin 立刻失效，新地址是 /你设的那串/login

  这个路径只在你访问它时才会下发给浏览器 —— 抓首页是看不出来的。

  忘了改成什么：用 SQLite 工具打开 data\moecard.db，
  查 system_settings 表里 setting_key='admin_path' 那一行。

═══════════════════════════════════════════════════════════
 人机验证（可选）
═══════════════════════════════════════════════════════════

  想挡住脚本刷单、撞库、薅券，可以接 Cloudflare Turnstile（免费）：

  1. 到 dash.cloudflare.com → Turnstile 新建一个站点，
     拿到 Site Key 和 Secret Key
  2. 后台 → 商城设置 → 人机验证，填进去并保存
  3. 点「测试配置」确认这对密钥能用
  4. 再打开总开关，勾选要验证的环节
     （后台登录 / 商品下单 / 订单查询 / 优惠券校验，可任意组合）

  注意：密钥填错会把所有人挡在门外，包括你自己 —— 后台登录页也进不去。
  所以务必先测试再开启。真被锁在外面时，用 SQLite 工具打开
  data\moecard.db，把 system_settings 表里 turnstile_enabled 改回 0 即可。

═══════════════════════════════════════════════════════════
 首页装修（可选）
═══════════════════════════════════════════════════════════

  轮播图：后台 → 商城设置 → 首页轮播图

  首页最上面那一块。放 1 张就是静态图，放多张每 5 秒自动切换，
  也可以点箭头、点圆点，手机上直接左右滑。最多 8 张。

  建议尺寸 1200×400（3:1）。图会按比例裁切填满，不会把版面撑歪。
  每张可以绑一个商品 —— 访客点这张图就直接进那个商品页；
  不绑就只是一张图，不会给出可点的假象。
  绑定的商品下架或删掉之后，那张图会自动变成不可点，
  不会把人带到 404，你不用回来手动清理。

  公告弹窗：后台 → 商城设置 → 公告展示

  写在页面里的公告很容易被划过去。开启弹窗后，公告会在进站时
  挡在面前一次；还可以开「强制阅读」，倒计时走完才让关。
  同一段公告只弹一次；你改了公告内容，所有人会重新看到一次。

  已售数量：后台 → 商城设置 → 商品展示

  商品卡片上的「已售 N」和详情页的「累计销量」。新店铺销量还小的时候
  摆出来反而劝退，可以先关掉，卖开了再打开。
  关掉之后接口也不再下发这个数字，不是只在页面上藏起来；
  后台的商品列表照常看得见真实销量。

  客服联系方式：后台 → 商城设置 → 客服联系方式

  可以配多条（Telegram / WhatsApp / 微信 / QQ / 邮箱）。
  页脚只显示一个「联系客服」按钮，点开向上弹出全部；
  Telegram 和 WhatsApp 点了直接跳转，其余点了复制。

═══════════════════════════════════════════════════════════
 用了 CDN 或反向代理（重要）
═══════════════════════════════════════════════════════════

  套了 Cloudflare、腾讯云 EdgeOne、阿里云 ESA、或者自己在前面加了
  Nginx 的话，服务器直接看到的是 CDN 的 IP，不是访客的。
  不处理的结果是：限流按 CDN 节点算（一个人触发全站被限），
  订单里记的下单 IP 也全是同一个。

  两步：

  1. .env 里加一行，然后重启：

         TRUST_PROXY=true

  2. 后台 → 商城设置 → 安全 → 客户端 IP 识别，看「当前识别到你的 IP」
     是不是你自己的公网 IP。是就配好了，不用再动。

  下面这些请求头是内置的，按顺序尝试，命中第一个就停：

      CF-Connecting-IP      Cloudflare
      EO-Connecting-IP      腾讯云 EdgeOne（默认回源头）
      EO-Client-IP          腾讯云 EdgeOne（自定义头的常见命名）
      Ali-Real-Client-IP    阿里云 ESA 边缘安全加速
      Ali-CDN-Real-IP       阿里云 CDN
      True-Client-IP        Akamai / Cloudflare 企业版
      X-Real-IP             Nginx 反代常见写法
      X-Forwarded-For       通用兜底，取最左边那个

  用别家 CDN，或者自己在 CDN 上配了别的头部名，就填在
  「自定义客户端 IP 请求头」里，一行一个，最多 5 个。
  自定义的优先于内置的。

  ⚠ 没有 CDN、直接把端口暴露在公网时，务必保持 TRUST_PROXY 关闭。
    开着的话任何人都能自己发一个 CF-Connecting-IP 冒充别的 IP，
    限流和风控就等于没有。

 开机自启（Linux）
═══════════════════════════════════════════════════════════

  一条命令：

      sudo ./moecard -install-service

  它会建一个专用用户、设好权限、按当前路径生成 systemd 单元文件、
  启用并启动。以后开机自动拉起，挂了也会自动重启。

  装完常用命令：

      systemctl status moecard      看状态
      journalctl -u moecard -f      看日志
      systemctl restart moecard     重启

  不想要了：

      sudo ./moecard -uninstall-service

  只撤服务，数据和配置一律不动。

  Windows 和 macOS 没有这个命令，用各自的服务管理工具。

═══════════════════════════════════════════════════════════
 升级与卸载
═══════════════════════════════════════════════════════════

  升级：

      sudo sh scripts/upgrade.sh

  会先备份数据库，问你一遍确认，然后停服务、换程序、起服务、验活。
  中间任何一步出问题都会自动换回旧版本并把服务拉起来。

  只想换程序不管服务：./moecard -update

  卸载：

      sudo sh scripts/uninstall.sh

  确认分两层。撤掉服务按 y 就行；要删数据的话，得把安装目录的
  完整路径手打一遍才算数 —— 里面是订单记录和没卖出去的卡密，
  一个 y 太容易顺手敲下去。删之前会先问要不要备份。

  只想撤开机自启、数据留着：sudo ./moecard -uninstall-service

  ⚠ 两个脚本都不接受在管道或定时任务里跑，一定要有人在终端前面。

 正式上线（重要）
═══════════════════════════════════════════════════════════

  在 exe 同目录建一个 .env 文件，至少填这三项：

      APP_ENV=production
      JWT_SECRET=<用 openssl rand -hex 32 生成，必须 32 位以上>
      BASE_URL=https://你的域名
      FRONTEND_URL=https://你的域名

  ⚠ BASE_URL 必须是公网可访问的地址 ——
    支付平台的异步回调会打到这里，填错就收不到支付通知，
    表现为「用户付了钱但订单一直是待支付」。

  ⚠ 生产模式下 JWT_SECRET 少于 32 位会拒绝启动，这是有意的：
    密钥太弱等于任何人都能伪造管理员登录态。

  建议在前面挂 Nginx 做 HTTPS，并把 TRUST_PROXY=true 加进 .env。
  完整配置说明见项目根目录的 .env.example 与 README.md。

 命令行参数
═══════════════════════════════════════════════════════════

  MoeCard.exe -version         查看版本与构建信息
  MoeCard.exe -config x.yaml   指定配置文件
  MoeCard.exe -skip-migrate    跳过启动时的数据库迁移

  MoeCard-migrate.exe -status                        查看迁移状态
  MoeCard-migrate.exe -create-admin -u 名 -p '密码'   命令行建管理员
                                                     （忘记密码时用）
  MoeCard-migrate.exe -backup                        备份数据库（一致性快照）
  MoeCard-migrate.exe -encrypt-codes                 加密历史明文卡密
                                                     （需先配 DATA_ENCRYPTION_KEY）

═══════════════════════════════════════════════════════════
 上线前请务必
═══════════════════════════════════════════════════════════

  1. 后台「邮件配置」配好 SMTP 并发送测试邮件
     —— 否则买家收不到卡密

  2. 后台「支付方式」添加渠道，把列表里的【异步回调地址】
     复制到支付平台的商户后台

  3. 后台「商家通知」配一个渠道（Telegram / Bark / 企业微信）
     —— 否则手动发货订单进来、卡密卖光了，你不会知道

  4. .env 里加一行 DATA_ENCRYPTION_KEY，开启卡密静态加密
     —— 数据库万一泄露，未售卡密不会被直接拿去用
     生成：openssl rand -hex 32
     ⚠ 这个密钥要和数据库分开保管，丢了就再也解不开

  5. 后台「管理员」开启两步验证
     —— 这里存着支付密钥和全部卡密，只靠一个密码不够

  6. 定期执行 MoeCard-migrate.exe -backup 并把备份挪到别处

  7. 用小额真实订单跑通一次：
     下单 → 支付 → 回调 → 发货 → 收到邮件

  API 文档：http://你的地址/api/docs

 界面说明
═══════════════════════════════════════════════════════════

  买家看到的商城前台     http://你的地址/
  管理后台               http://你的地址/admin

  后台侧栏最下面有「关于」，放着项目地址、Telegram 频道和群组，
  以及你这个包的版本号 —— 反馈问题时把那几行一起发过来。

  两者共用同一套「暖色仪表盘」视觉：暖白底、白色圆角卡片、
  柔和投影、青(#4a9d9a)/琥珀/陶土配色，买家端和管理端观感一致。

  两套界面在同一个程序里，不需要分别部署。
  正文与信息性文字的对比度均达到 WCAG AA 4.5:1，
  并且带「减少动态效果」降级（跟随系统无障碍设置）。
